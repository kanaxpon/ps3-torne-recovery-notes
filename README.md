# PS3 torne 録画救出・調査ノート

自身が保有するPS3とtorne録画について、バックアップの保全、録画データの抽出、再生に必要な条件を調べた記録です。Windows / PowerShell / Python 3を主な作業環境としました。

**録画データの保全・抽出と、PCで再生できる形への救出は別です。後者は未達成です。** このリポジトリは完成した復号ツールや一般向けの実機操作手順ではありません。

## 現在地

| 項目 | 結果 |
|---|---|
| バックアップの作業用コピーと整合性検査 | 実施 |
| 録画本体と管理情報の保全 | 実施 |
| 188バイトTSへの整形 | 実施。ただしスクランブルは残存 |
| 元チューナーの限定的な起動・認証試験 | 成功した段階あり |
| 保存録画の鍵設定試験 | エラーで停止 |
| 正規再生中の情報を読むサービスの接続確認 | 成功 |
| 正規再生中の鍵候補のメモリ読取り | 未実施 |
| コンテンツ復号・PCでの実再生 | 未達成 |

最後に、録画アプリの起動操作後、USB接続コントローラーを要求する低解像度の画面が出たとの報告があり、作業を中断しました。セーフモードかどうかは画面未確認で、原因も特定していません。プラグインとの因果関係や、録画の損失は確認していません。再開時は本体の状態確認を優先します。
